# 制作细节

## 合成结构

可按以下职责分层，沿用已有工程命名与组织：人物 RGBA → 眼睑/发丝动作 → 人物 MASTER → 场景与主题特效 → 显示面板（界面截图 + 动画窗口）→ 三维展示舞台（相机、面板、出屏特效）→ 最终输出与音轨。

保留独立场景控制器和显示控制器，两者使用同一周期及相位。导入另一 AEP 时先记录新增 item，避免名称冲突；若重命名被表达式引用的合成，同步更新其中 `comp("旧名称")` 引用，包括单引号引用，保留表达式启用状态。导入后采样表达式并检查 `expressionError`，再替换活动人物源。

## 人物 RGBA、发丝与眨眼

- 优先使用认可抠图的 RGB 与 alpha，不自动套上去灰、调色、白色反光或轮廓光。在亮、暗背景检查发丝；只校正衣服等实体区域内部的透明噪声，不把细发丝压成硬边。新做抠图时保持身份、服装与姿态，实际视觉核对后再作为动画源。
- 分离活动刘海、左右悬空发束，以及固定脸部、头顶和衣服。活动发束后方需要补回静止底图缺口；补片不能重绘或拖动五官。
- 原项目 V10 使用真实 AE 原生高级 Puppet（`ADBE FreePin3`）网格与位置点。仅添加空 Puppet 效果并不等于拥有可用网格；须通过 AE 可用界面/自动化创建实际位置点，并枚举、核实网格和位置点数量。
- 发根和密发区固定；沿中段到发梢逐步增加风力权重与响应滞后。弯曲刘海时按原始相邻控制点段长旋转、累加位置，降低拉长或断裂风险。参考逻辑：`p[j] = p[j-1] + rotate(rest[j]-rest[j-1], bend[j])`；固定前两个发根点，其后角度随位置权重与风场变化。
- 不同发束共享缓动/阻尼风场，但使用不同相位与延迟。增大幅度时先查网格边界、透明遮罩和静止底图是否暴露，再增加数值。
- 双眼用局部眼睑补片或认可动画源，共用闭合曲线。眨眼控制包括间隔、首次时间、持续时间；原项目间隔最终为 1.5 秒，原闭合动作约 0.30 秒。检查睁眼、闭眼、重新睁眼，双眼不能只闭上一只。
- 数值验证应与实际画面对照：取风力两端及回摆帧，比较固定五官/衣服区域；对必须保持段长的刘海检查相邻点距离。坐标、位置点数与幅度属于具体素材，不能套用到新人物。

## 角度驱动背景与特效

以通用 `Scene Mix` 或各场景权重控制背景及对应特效；常驻特效可独立于场景权重。名称与场景语义保持一致，不把所有主题命名为 Snow Mix。原项目的 Snow Mix 是樱花/雪夜这一对场景的具体实现，以下仅用于解释该案例。

设置 `theta = manualOffset + angleRange*cos(2*pi*time/cycle)`，再用角度、切换位置和可调过渡宽度/时间计算连续 `Snow Mix`（0–100）。雪夜背景和雪花用 Snow Mix，樱花背景/花瓣用其互补值；人物保持独立，不随背景透明度一起消失。

原项目从突然的条带阈值切换改为约 1.2 秒缓动过渡，周期 4 秒。需要时间恒定的过渡时，按当前周期和角度曲线校准开始/结束时刻；不要改周期后仍照抄旧角度宽度。背景可带小幅视差，使用放大后的素材覆盖所有位移极值。

## 按主题选择特效

优先按用户指定种类、已有素材或参考确定形态、运动方向、寿命、颜色、混合方式和场景联动。缺少对应素材时，可按需要制作可编辑矢量、透明图像或使用原生程序效果；不因来源工程有花瓣/雪花就沿用其内容。仅改变颜色或贴图无法替代不同运动模型。

| 类型示例 | 主要运动与细节 | 制作判断 |
| --- | --- | --- |
| 花瓣、落叶、纸屑 | 风场、翻面、重力下落、大小差异 | 调整重量、旋转和阻尼，避免同速同相 |
| 雨滴、雨线 | 方向一致的快速下落、拉长与模糊 | 按场景决定是否需要碰撞、水花或湿润痕迹 |
| 火星、余烬 | 上升、湍动、亮度与尺寸随寿命衰减 | 控制发光和叠加，避免冲掉人物曝光 |
| 光点、萤火、星尘 | 缓慢漂移、闪烁或指定轨迹 | 按主题决定是否跟随风场或人物运动 |
| 烟雾、雾气、能量流 | 连续流动、扩散和消散 | 使用连续纹理/形状，处理透明叠合与循环接缝 |

分层、避脸、可编辑控制器、场景同步和出屏是通用方法；不是每种特效都需要同样的层数、向下速度或粒子数量。烟雾等连续效果用流速、尺度、湍流、透明度控制，不能强制套用“粒子数量”。

## 分层与景深：原项目花瓣/雪花示例

以下形态、尺寸、数量与素材仅适用于原项目复现；其他特效沿用分层原则并重新设计运动和细节。

| 层级 | 形态和运动 | 放置与景深 |
| --- | --- | --- |
| 远景 | 小、密、慢、低振幅 | 人物后方，略柔化 |
| 中景 | 可读的花瓣/雪粒，中速 | 人物前后错层，主体清晰 |
| 近景 | 大、稀疏、更快、滞后较小 | 人物前方，轻度模糊 |
| 镜头前 | 很大、很稀、快 | 构图边缘，明显失焦，避开眼鼻 |

固定随机种子以便比较修改前后。位置循环在画面外重置，进入/离开区域加淡变，避免边缘跳跃。密度参数控制出现数量或分布，速度、尺寸、模糊分别可调。性能吃紧时优先对整层模糊，避免每个远景粒子添加重复效果。

花瓣可用多种 128×128 透明矢量预合成：不规则心形缺口、柔和粉紫背光、暖色透光高光、折痕、薄边和低对比细纹。用 X 缩放模拟侧向翻面，保留小的最小厚度，再叠加缓慢滚转、起伏和风场漂移。原项目细节叠加为 28 枚中景、8 枚近景、4 枚镜头前，共 40 枚、6 种花瓣，叠加于已认可的远景天气之上。

雪花以不规则透光颗粒、聚合冰粒为主，少量六枝冰晶；冰晶细枝要在目标尺寸上可见，避免全画面都是大星形。原四层雪为 120/80/32/8 枚；最终又增加 36/12/4 枚细节，共 52 枚、6 种雪粒/冰晶。数量用于原案例复现，新增任务依密度、画幅和机器资源调整。需要替换旧粒子时关闭明确的旧层，避免意外加倍。

## AE 界面、人物中心与顶部接缝

1. 获取实际界面截图，记录合成预览窗口的矩形及人物中心坐标。截图作为界面框，动画填入原预览区域。
2. **先清掉截图内全部静止照片像素**：覆盖原预览区域的底色，放在动画下、截图相关残留像素上，或直接准备透明开口的界面框。遮盖范围包含预览窗四周残边；动画仅略微放大补边。用错误截图裁切加大位移会产生原项目的顶部静止撕裂。
3. 将面板变成 Classic 3D 图层，anchorPoint 对齐面板坐标中的人物中心，position 位于输出中心；相机指向显示面板。
4. Y 轴旋转表示左右透视；降低 X 倾斜、Z 滚转及手持抖动，另加水平位移。原参数 22° / 0.55° / 0.12°、水平 65px、周期 4s。`x = width/2 + sway*cos(2*pi*time/cycle)`。场景切换相位与此共用；参考若相位不同，以视频对齐。
5. 用面板超扫描和允许的界面裁切覆盖输出。原面板为 1856×1009、人物 pivot 约 [950,430]、面板 scale 111%；这些坐标和比例依截图而定。测试整个周期的极值，不以单张预览判断无黑边。

## 特效从场景延伸到界面外

需要出屏时，在展示舞台上保留独立可越界的特效层，并按其形态设计空间运动。离散粒子可用下述父子级和深度路径；光带、烟雾等连续效果使用跨边界路径或连续体积/透明层，处理内外衔接与遮挡，不强制拆成花瓣式粒子。

在三维展示舞台上添加独立 3D 花瓣/雪花，作为面板图层子级；从场景窗口侧边或下边附近出发，沿面板局部坐标越过预览矩形进入工具面板/时间线区域，同时向相机移动。不能把所有粒子都放在裁切后的场景预合成内。

原项目出屏为 12 枚花瓣与 16 枚雪花，寿命约 3.1–4.1 秒，局部 Z 从约 -45 到 -265（在该相机位于负 Z 的工程中向镜头靠近）。新的相机配置先核对深度方向；不要无条件使用负 Z。令 `u=age/lifetime`，`q=u*u*(3-2*u)`，横向与深度使用 q，垂直随 u，生命周期首尾淡变。该案例共享 Snow Mix；其他主题使用对应场景权重或独立强度，保留适合其形态的控制参数。世界投影、面板旋转、遮挡、失焦和脸部避让一起检查。

## 配乐

若需找新音乐，读取当前来源与使用条件；保存来源链接和可适用条件，不能把曾经使用过等同于可在所有用途使用。用户要求试听时先提供可播放片段，认可后合入。

原片为 12 秒，选段做约 0.35 秒淡入、1.2 秒淡出，振幅约 0.75。可先制作对应 WAV 再导入最终合成，或在 AE 音频层完成包络；避免 WAV 已淡变后再重复处理。已有无声视频无需重新渲染视觉层，可复制视频流并新增 AAC 音轨；工程同步保留实际音源与音轨。
