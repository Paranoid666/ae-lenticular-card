# 从原照片生成可替换背景

## 读取照片与确定方向

实际查看原照片；本地图片先用 `view_image`。把照片作为主题、光线和构图参考，背景单独生成，不把照片中的人物复制到新背景。分析：

- 场景线索、服装、道具、姿态和照片情绪；只依据可见内容与用户要求，不把推测的拍摄地点或人物身份当成事实。
- 光源方向、软硬、明暗、色温及轮廓光；优先让背景适配认可人物的光线与颜色。
- 相机高度、视线、透视、地平线及人物大小；近景肖像不自动补成全身站姿。
- 人物在最终画幅中的位置、轮廓与背景对比；为脸部和发丝保留可读区域，并为视差、旋转和裁切留边。

用户已给明确主题就遵循；没有明确主题时，agent 根据照片选择合理场景并简短说明依据，直接推进生成。不要固定为樱花街道、雪夜，也不要因为来源工程有两套背景就无条件增加场景数。需要左右视角切换的效果时，按任务生成相应数量的协调场景。

## 生成背景资产

优先使用内置 `image_gen`，执行时读取可用的 imagegen 技能。将原照片标为参考图，将已有背景标为编辑目标或结构参考；按当前工具的图片引用机制传入，不能仅在提示中描述文件路径当作已提供图片。遵循工具实际支持的参数，不要求用户另接推理 API。工具不可用或生成失败时报告情况，保留已有素材或待执行提示；未经用户选择不切换到额外 API 路径。

提示说明以下内容即可：

```text
用途：AE 动态光栅卡的独立背景资产。
参考角色：原照片用于主题、色调、光线和相机视角参考，人物将由 AE 单独合成。
场景：依据当前照片与用户要求确定的环境、气氛和变化。
构图：匹配最终画幅、人物预定落位、相机高度和透视，四周留足视差与旋转裁切余量。
光线：匹配人物原片的光向、色温与明暗关系。
限制：背景中不复制原人物，不加入无关人物、文字、水印或 AE 界面；需要独立动画的粒子/光带等不烘焙进背景。
```

选择适合原照片的写实、插画或其他风格，避免未经要求改变风格。具体生成尺寸以工具能力为准，之后核对实际输出尺寸和目标裁切是否足够；提示中的“高清”不等于已获得目标像素尺寸。

## 协调场景变体

需要同一场景的季节、天气、昼夜或风格切换时，先建立基础背景，再以其作为结构参考或编辑目标生成变体；保持主要建筑、空间布局、透视、地平线和人物落位区域，改变任务指定的环境因素。若用户要求不同场所，允许结构变化，但校准切换节奏与人物落位。

切换背景、颜色和对应主题特效共用场景权重；无需切换的特效独立控制。避免让背景变体自动重绘人物或把新的粒子永久画进背景。原项目的樱花/雪夜只是同一空间变体的一种示例。

## 合成检查与可替换交付

逐张查看生成结果，再把认可人物 RGBA 叠在目标位置检查：光线是否协调、尺度与透视是否合理、头发是否融进背景、脸旁是否有干扰细节、变体结构是否稳定、极端摆动是否露边。针对具体问题修改背景，不随意重生成已认可的人物。

把选定背景从生成工具的默认存储位置复制到当前项目素材目录，使用清晰的版本名，如 `background-scene-a-v1.png`，并保留提示和实际参考角色说明。AEP 引用项目内的素材，不只依赖生成缓存。

每套背景作为独立 footage 和背景预合成，使用统一的画幅、中心/基准定位与覆盖逻辑；暴露必要的缩放、偏移、视差与混合参数。背景替换时核对新尺寸，重新计算 cover 和超扫描范围，不沿用旧素材坐标假定所有图片等大。更新相关素材引用并检查所有变体，人物、特效和界面层保持独立。

用户明确要求先预览时，先提供背景样图及人物叠加预览，认可后再合入整片；没有阶段确认要求时完成生成、合成与验证即可，不增加审批步骤。
