# 来源与原项目版本

本技能提炼自一个 AE 人物动态光栅卡项目的工程说明、制作脚本和最终视频抽帧。以下版本名用于解释制作决策；不包含原工程和人物素材，使用者须提供自己的输入。

## 原案例目录约定

原工程将交付 AEP 与素材放在 outputs，将制作及验证脚本放在 work；另有独立的强风人物工程作为导入来源。新任务使用当前工作区和实际素材位置。

## 原工程定位

- 人物源与动作：`V10_01_木偶发丝与双眼动画`、`V4_01_局部眼睑动画`；强风导入使用 `A3_` 前缀。
- 总场景：`V2_01_参考风格展示` / `V2_CONTROLS`；`V2_06_` 为场景与人物合成。
- 界面面板：`DISPLAY_01_真实AE界面与动画`。
- 三维舞台：`FINAL_720p24_大幅左右摇摆低旋转`，含 `DISPLAY_CONTROLS_可调展示参数` 与 `人物中心_左右转动_场景跟随_满画幅`。
- 最終外层：`FINAL_720p60_精细雪花与粒子出屏`，加入声音后沿用。
- 界面图片：`outputs/AE界面展示外框.png`；背景与人物等依赖必须按工程实际路径核对。
- 音源为 pianocafe_Kumi 的 Japanese Piano~sakura，原工程记录 Pixabay条目318108，导入的是 `outputs/配乐素材/Japanese_Piano_sakura_12s_fade.wav`。后续使用须重新核对素材是否存在及适用条件。

## 需要查原实现时

原 `work/` 的下列脚本可用于只读核对实现，**不能直接在新任务执行**：包含固定工程名、绝对路径、具体素材坐标、全局偏好修改及队列状态操作，须先按当前任务改写并审查。

- `animate_puppet_v10.jsx`：真实网格枚举、固定点、按段长刘海弯曲。
- `merge_v3_strong_wind.jsx`：导入AEP、表达式名称重写、人物尺寸桥接。
- `add_falling_weather.jsx` / `improve_snow_depth.jsx`：共享风场、天气占比、四层雪。
- `build_interface3d.jsx` / `center_interface3d.jsx` / `increase_horizontal_sway.jsx`：界面3D、人物中心、大幅水平摇摆。
- `fix_top_seam_60.jsx`：截图残边清理及混合帧率外层。
- `build_detailed_petals.jsx` / `build_weather_popout.jsx`：原生花瓣、冰晶与出屏父子级。
- `assemble_weather_popout.py`：720帧连续性、H.264编码和完整解码。
- `add_sakura_music.jsx`：最终合成加入已处理WAV。
